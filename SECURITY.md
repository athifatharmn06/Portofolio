# Security

This is a static personal portfolio (React + Vite) with no backend, database or user accounts.

## Reporting a vulnerability

Please report security issues privately through GitHub's
["Report a vulnerability"](https://github.com/athifatharmn06/Portofolio/security/advisories/new) form
or by email to athifadheel@gmail.com. Do not open a public issue for security problems.

## Repository protections

- `main` is protected by a ruleset: pull request required, linear history, signed commits,
  no force pushes, no deletions.
- Secret scanning with push protection and Dependabot alerts and security updates are enabled.
